[C++] Implement RUM actions

Once RUM views are implemented, we'll want to expose APIs for tracking Actions within the scope of a View.

D.o.D.

- Both C and C++ APIs have functions for creating and manipulating discrete actions and long running actions (through start / stop action)
- In the implementation layer, we generate events in response to those API calls
- The example program sends RUM Action events to intake
- Actions track the number errors that occur during their duration and send this count to intake (see other platforms for examples)

## Questions

1. **Action Types**: Which action types should be supported initially? The design docs mention CUSTOM, CLICK, SUBMIT, NAVIGATION, LOAD, TAP, SCROLL, SWIPE.

2. **Action-View Relationship**: How should actions behave when no view is active? Should we auto-create a "background" view or reject the action?

3. **Action Timeout**: Should the 10-second action timeout be implemented with a background timer, or checked on subsequent API calls?

4. **Action Identification**: For continuous actions, should we use generated action IDs or action type+name combinations for start/stop correlation?

5. **Error Tracking Integration**: How should actions track errors that occur during their duration? Do we need an error reporting API first, or can we stub this?

6. **Concurrent Actions**: Should multiple continuous actions be allowed simultaneously, or only one per view?

7. **Action Attributes**: Should actions support custom attributes like views do?

### Step 10: Update Examples with Action Usage
**In `examples/c/main.c`:**
```c
dd_rum_start_session(rum);
dd_rum_start_view(rum, "main-screen", "Main Screen", NULL);

// Discrete action
dd_rum_add_action(rum, DD_RUM_ACTION_CLICK, "login-button", NULL);

// Continuous action
const char* load_action = dd_rum_start_action(rum, DD_RUM_ACTION_LOAD, "user-data", NULL);
sleep(2); // Simulate loading time
dd_rum_stop_action(rum, load_action, NULL);

// Action by type (no action ID needed)
dd_rum_start_action(rum, DD_RUM_ACTION_NAVIGATION, "profile-page", NULL);
sleep(1);
dd_rum_stop_action_by_type(rum, DD_RUM_ACTION_NAVIGATION, "profile-page", NULL);

dd_rum_stop_view(rum, "main-screen", NULL);
dd_rum_stop_session(rum);
```

**In `examples/cpp/main.cpp`:**
```cpp
rum->StartSession();
rum->StartView("main-screen", "Main Screen");

// Discrete action  
rum->AddAction(datadog::RumActionType::CLICK, "login-button");

// Continuous action with attributes
std::string load_action = rum->StartAction(
    datadog::RumActionType::LOAD, 
    "user-data",
    {{"data_size", datadog::Attribute(1024)}}
);

std::this_thread::sleep_for(std::chrono::seconds(2));
rum->StopAction(load_action, {{"status", datadog::Attribute("success")}});

// Action by type
rum->StartAction(datadog::RumActionType::NAVIGATION, "profile-page"); 
std::this_thread::sleep_for(std::chrono::seconds(1));
rum->StopActionByType(datadog::RumActionType::NAVIGATION, "profile-page");

rum->StopView("main-screen");
rum->StopSession();
```
