[C++] Implement RUM views

Once we have a RUM feature that keeps track of session state, we'll need to implement the concept of a RUM View.

D.o.D.

- Both C and C++ APIs have functions for creating and manipulating views
- In the implementation layer, we generate events in response to those API calls
- The example program sends RUM View events (with all required properties, including session properties) to intake

## Questions

1. **View Lifecycle Model**: Should we support multiple simultaneous active views (complex) or single active view (simple)? The design docs mention both approaches.

2. **Session Integration**: Should starting a view automatically start a session if none exists? How should views behave when session sampling is disabled?

3. **View Event Timing**: When should view start events be sent? Immediately on `startView()`, or batched? When should view stop events be sent?

4. **View Key vs View ID**: Design docs mention both view keys (user-provided) and view IDs (generated UUIDs). How should these relate in the API?

5. **Custom Attributes**: Should view attributes be strongly typed or use the existing `Attribute` system? How do we merge attributes from start and stop calls?

6. **Error Handling**: How should the API handle invalid view operations (stopping non-existent view, starting view with existing key, etc.)?

7. **Upload Integration**: This work item requires actually sending events to intake. Do we need to implement the full upload pipeline, or can we stub/mock it?

### Step 9: Update Examples with View Usage
**In `examples/c/main.c`:**
```c
dd_rum_start_session(rum);

// Create view attributes
dd_attribute_t* view_attrs = dd_attribute_object_create(2);  
dd_attribute_object_set_string(view_attrs, "screen", "main");
dd_attribute_object_set_int(view_attrs, "version", 1);

dd_rum_start_view(rum, "main-screen", "Main Screen", view_attrs);

// Simulate some activity
sleep(1);
dd_rum_add_view_timing(rum, "content_load");

dd_rum_stop_view(rum, "main-screen", NULL);
dd_rum_stop_session(rum);

dd_attribute_destroy(view_attrs);
```

**In `examples/cpp/main.cpp`:**
```cpp
rum->StartSession();

std::map<std::string, datadog::Attribute> view_attrs{
    {"screen", datadog::Attribute("main")},
    {"version", datadog::Attribute(1)}
};

rum->StartView("main-screen", "Main Screen", view_attrs);

// Simulate activity
std::this_thread::sleep_for(std::chrono::seconds(1));
rum->AddViewTiming("content_load");

rum->StopView("main-screen", {{"final_status", datadog::Attribute("success")}});
rum->StopSession(); 
```
